# 图片区域定位与亮度误报过滤（定位算法始于 0.3.0，文字集成更新至 0.4.0）

输入仍是原分辨率、不透明、8 位 PNG，CPU 运行，不使用 OCR、神经网络、GPU 或图像缩放。这里的“图片噪声”指封面、照片等正常内容造成的背景误报，不对原图去噪或改变图片亮度。

## 算法与来源

| 处理 | 采用方法 | 来源与关系 |
| --- | --- | --- |
| 平坦 UI 底色估计 | 局部 RGB 标准差、Sobel 梯度、量化颜色频数与实际颜色中位数 | 项目工程规则；Sobel 使用 OpenCV 基础算子 |
| 候选生成 | 非底色像素、3×3 开闭运算、8 邻域连通域 | 形态学参考 Haralick 等（1987）；CCL 使用 OpenCV 默认实现 |
| 图片证据 | 纹理覆盖率、4×4 网格覆盖、主色占比、边界明暗／颜色变化 | 项目自定义规则，不是图片语义识别模型 |
| 范围与重复布局 | 原始／裁剪候选比较、尺寸相似、行列对齐及间距 | 项目自定义规则；重复布局只加分，不能替代图片证据 |
| 候选内部支持 | SLICO 超像素分割，候选边界附近保留保护带 | 直接调用 OpenCV SLICO；参考 Achanta 等（TPAMI 2012） |
| 背景后处理 | 可信内部掩码、边界与不确定候选复核、剩余 UI 统计 | 项目自定义规则，与论文原始任务不同 |

SLICO 来源：[R. Achanta 等，SLIC Superpixels Compared to State-of-the-Art Superpixel Methods，TPAMI 2012](https://doi.org/10.1109/TPAMI.2012.120)，[作者机构说明](https://www.epfl.ch/labs/ivrl/research/slic-superpixels/)。基础形态学参考：[Haralick 等，1987](https://doi.org/10.1109/TPAMI.1987.4767941)。SLICO API 见 [OpenCV ximgproc](https://docs.opencv.org/4.x/df/d6c/group__ximgproc__superpixel.html)。

本实现不是先对整页进行 SLICO 再识别图片：为控制 CPU 与内存，先用工程特征提出范围，再在候选的原图 ROI 和外围小带执行 SLICO。分割用于限制跨边界超像素、生成内部支持掩码，**不能作为独立证据证明候选是图片**，也不保证精确还原封面轮廓。每个 ROI 直接裁取原始像素，未降采样。

## 处理步骤

1. 用与截图宽度相关的小窗口求 RGB 标准差和 Sobel 边缘密度，记录哪些位置同时存在颜色变化与边缘细节。
2. 从足够平坦、像素占比达到要求的位置学习常见 UI 底色。量化只用于统计颜色桶，底色使用桶内原像素中位数。生成两类候选掩码：排除所有常见底色；以及存在暗色 UI 时只排除较暗底色。后者用于保留封面中的大块白色天空，前者用于从白卡内部找出嵌入图片。
3. 以独立的 3×3 开闭运算和连通域生成候选，再筛选原图面积、宽高与形状。此处开运算只用于图片候选，不作用于背景窄边分支。
4. 比较原范围与按行列占用率去掉狭窄附着部分后的范围，选择证据分数更高的一项。浮动按钮可能与大封面接触，因此不能无条件保留整个连通域的外接框。
5. 检查细节总覆盖率及 4×4 网格中的空间分布；主色占比过高则拒绝，减少把纯色按钮和密集文字卡片当作图片。检查内外各几像素的颜色差，至少有两侧可测；支持截图边缘缺一侧的候选，但不保证所有裁切图片都能发现。
6. 将内部证据合格的候选去重，依据相近尺寸、同列／同行、合理间隔增加布局支持。默认不要求存在同伴，单张大图也可采用。可信判定同时要求置信度、边界支持和候选填充达到各自门限；布局加分不能绕过这些条件。
7. 对可信候选运行 Lab 色彩输入的 SLICO，默认 4 次迭代，执行标签连通性处理。按每个超像素位于有效候选内部的比例选择支持标签，结果裁回候选和有效像素范围。内部再留出约截图宽度 0.2% 的边界带。若分割支持覆盖不足，整个候选降为待复核，不自动排除。

无足够常见平坦底色、边界很弱、内部颜色过于单一等情况不会强行认定图片。默认最多分析 80 个候选，达到上限标记模块 `partial`，不把未完成分析记为通过。

## 与背景、文字链路的关系

`pictures.interior` 不写入 `frame.valid` 或 `ignored_regions`。背景分析可排除可信内部；0.4.0 文字分析也读取此掩码，但只用于加强内部候选的配对数量、宽度一致性及位置覆盖要求，不把像素从文字链路删除，也不改变实际测量颜色。图片内部配对失败的碎片只计入诊断，稳定底色上的标签和数字仍可检出。细节见[文字算法](text-algorithm.md)。

块状背景从原图有效区扣除可信图片内部后生成候选，外围背景取样与纹理统计也排除这些内部像素。边界带和不确定图片不自动删除；与其重合较多的背景告警降为复核。

窄边必须从未扣图片掩码的原始阈值连通域判定，避免把掏掉图片内部后剩余的带状像素制造为假边框。原始连通域主要落在可信图片内部时过滤；真实图片外的细边继续保留。图片与外边框粘连成同一亮区时仍可能难以区分，不能承诺边框完全不漏。

全页中位数、亮暗比例保留原图统计；整页未适配判断改用剩余 UI 的亮暗比例、最大低纹理亮区比例。剩余 UI 占比不足（默认 8%）则背景模块标记 `partial`、要求复核；若仍有其他确定异常，整页可同时为 `failed`。不确定图片占大部分剩余亮区时，整页告警也降为复核。

图片模块异常时记录 `modules.pictures.status=error` 与错误信息，回退到不排除图片的背景检测，文字仍运行；默认报告 CLI 也返回执行错误码 2，不会静默通过。

## 输出与配置

- `statistics.pictureRegions`：原图坐标、工程置信度、纹理／网格覆盖、边界支持、重复同伴数、采用／不确定分类、采用时的超像素数和内部像素数。
- `statistics.pictureInteriorPixelCount`、`pictureBoundaryPixelCount`：实际掩码计数。
- `uiPixelRatio`、`uiMedianLuminance`、`uiBrightPixelRatio`、`uiDarkPixelRatio`、`uiLargestLowTextureBrightRegionRatio`：背景链路扣除可信内部后的统计；原图 `medianLuminance`、`brightPixelRatio`、`darkPixelRatio` 仍保留。旧的最大亮区字段则来自本次背景候选，不应当作未过滤的原图统计。
- `pictures.png`：有候选时额外生成原尺寸定位图。绿色是采用的候选范围，橙色是未自动排除的候选，矩形不代表框内所有像素都被忽略。
- 调试模式另存 `pictures_texture`、`pictures_proposals`、`pictures_slico_boundaries`（有可信候选时）、`pictures_interiors`、`pictures_boundaries` 掩码。

全部配置位于 `skinscan/config.py` 的 `pictures`。例：

```yaml
pictures:
  enabled: true
  high_confidence: 0.80
  min_boundary_support: 0.65
  min_texture_coverage: 0.30
  min_grid_coverage: 0.50
  slic_region_width_ratio: 0.012
  slic_passes: 4
  min_segment_support: 0.50
  min_segment_coverage: 0.85
  min_ui_area_ratio: 0.08
```

可按 `pages.<pageId>.pictures` 覆盖。`pictures.enabled: false` 关闭该分支，用于比较或排查。置信度是工程评分，不是经统计校准的图片概率。形状规则、分值权重和网格等部分组合常数固定在实现中，不能声称每个细节都可配置。

SLICO 依赖 `opencv-contrib-python-headless`；不要与其他提供 `cv2` 的包混装。PNG 输入要求保持不变，其他格式须先由用户认可的采集／转存流程生成无损 PNG，不能只改扩展名。

## 验证与限制

回归包含：独立彩色／灰度图片、大片白色天空、白卡内部嵌图、图片旁弱文字、单像素外框、密集文字和纯色按钮负样本、重复布局、忽略区域、关闭分支、模块故障、图片主导整页、剩余 UI 不足、配置验证及原尺寸报告。

纯色封面、极简文字海报、没有边界的图片可能定位失败；相近底色导致封面范围收缩，边界遮挡、悬浮 UI 与图片叠加也可能使定位不完整或包含叠加组件。不能从截图恢复被遮挡的语义层级。LBP、图分割对照和语义封面分类本版未实现；现有合成测试与单张业务示例不能代表生产误报率或召回率。
