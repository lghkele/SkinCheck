# 方案实现映射

修订后的[总体方案](android-dark-mode-screenshot-detection-plan.md)融合 0.2.0 的两项文字算法优化、0.3.0 的图片定位过滤与 0.4.0 的文字候选验证，并按处理环节标注算法、论文／标准来源、改编关系及实现状态。

输入设计对应 `skinscan/cli.py` 和 `skinscan/image.py`：无损 PNG、sidecar/manifest 元数据、原分辨率加载、忽略掩码及输入错误报告。

图片定位对应 `skinscan/pictures.py`：平坦底色候选、原分辨率局部纹理与边界证据、重复布局支持；仅对可信候选的原图 ROI 执行 Lab SLICO，生成内部支持掩码。该掩码用于背景候选、外围取样及剩余 UI 统计；0.4.0 起也作为文字内部证据要求的上下文，文字保持完整像素。边界／不确定候选保留复核，UI 太少和模块错误明确标记。详见 [图片算法说明](picture-algorithm.md)。

背景 PoC 对应 `skinscan/background.py`：全页亮度统计，绝对/相对/独立局部阈值分支，连通区域，面积、矩形度、均匀度和外围反差，独立原始掩码窄边分支。全页判定需要低纹理的大亮区，不只根据亮色比例判定。形态学核按截图宽度计算，最小为 3 像素；窄边分支不会经过该闭运算。

文本检测对应 `skinscan/text.py` 和 `skinscan/strokes.py`：两种极性、多尺度形态学、局部噪声门限、Sobel 弱边缘、连通组件和水平组合。0.2.0 起采用相反梯度边缘配对、按局部宽度采样笔画核心及两侧背景，逐组件确认支持后组合局部异常文本。默认使用文字极性和局部背景联合约束，排除白底灰字等专项范围以外的组合；`all_low_contrast` 可恢复全量可读性检测范围。0.4.0 起通过 `textshape.py` 增加字缝／容器同色连通和宽度一致性验证，失败时可重测 ±12°；删除整行估色回退，只对较强 UI 文字排列保留无测量未知项，不生成估算对比度。完全同色的背景空隙和与候选极性不符的颜色被排除。短文本不因字符数不足被丢弃，但降低置信度并要求复核。详见 `text-algorithm.md`。

误报治理对应 `skinscan/image.py`、`skinscan/engine.py`：纹理评分、页面/坐标/颜色白名单、重复证据合并、背景与文本层级、风险和置信度独立输出。模板匹配不在本次实现范围（原方案标为可选）。

CI 对应 `skinscan/cli.py` 和 `skinscan/report.py`：有限并发、独立检测链路异常隔离、原图/标注图/JSON/HTML、每次运行独立历史目录、人工审核记录和严格退出码。批处理为截图级线程池，单张先执行图片定位，再将两条独立链路并行。OpenCV 在 CLI 中限制为单内部线程，避免线程池叠加失控；库 API 使用者可以自行设置 OpenCV 线程数。峰值内存受并发数和图片复杂度影响，可先使用 `--workers 1`。

## 验收与后续校准

运行 `python -m pytest -q` 检查合成用例及工程行为。运行示例样本生成器，再通过 manifest 批量扫描，可以检查报告和完整分辨率耗时。`summary.json` 保存本次总耗时、单张平均耗时和 P95；`durationMs` 包含图片读取和算法，不包含保存图像/报告的时间。并发场景的单张耗时包含 CPU 竞争。

建议为真实截图人工标注 `pageId`、问题类型、坐标及是否为允许的设计，另存固定输入集。先固定阈值测量背景/文本召回和页面误报，再独立评估高置信度阻断准确率。不要直接把合成测试通过数当作生产准确率，也不要用未标注截图给出百分比保证。

当前文本分组偏向水平文字；竖排、装饰字体、极细字体和图片上的文字属于低可靠场景。纹理规则会降分并保留候选，但无法理解图片语义，纯白海报与白卡片可能完全相同。单字与图标也可能拥有相同像素，必须允许人工确认。检测状态 `passed` 仅表示本次启用的规则未发现异常，不保证所有控件均可读。

人工复核结果保存为单独工件，保留历史；当前不会训练模型、自动更新白名单或事后改写机器判定。性能和内存验收应在目标 CI 主机、真实分辨率、代表性复杂截图上重新测量。

## 初版 0.1.0 本机验证记录

- Python 3.9.6、OpenCV 4.14.0、NumPy 2.0.2、PyYAML 6.0.3；42 项 pytest 用例通过。
- 标准 wheel 构建、安装、在项目目录外调用 `skinscan --version` 均成功，`pip check` 未发现依赖冲突。
- 示例生成器的 10 张 1080×2400 PNG，以 2 个截图并发运行：正常暗色页 `passed`；白卡片、黑字深底、白字浅底、局部灰卡片、整页亮色共 5 张 `failed`；窄环、三边、短文本和复杂图片共 4 张 `uncertain`。这些是合成输入的预期分流，不代表真实业务准确率。
- 此次运行包含产物写出的总耗时约 5.72 秒；单张算法平均约 0.96 秒、P95 约 3.09 秒，最慢为复杂纹理图片。两并发进程峰值 RSS 约 664 MiB（包含 Python、OpenCV 和所有处理中间数组）。当前实现不能承诺原方案中“几十 MB”的内存估计；资源受限环境应减少并发，并用实际截图单独测量。
- 结果保存在 `reports/20261019T101821Z-03e4a5c7/`；机器 JSON 和标注 PNG 均按原始分辨率保存，原图复制内容经测试保持一致。

## 0.2.0 算法优化验证

- 63 项 pytest 用例通过；新增极性/局部背景门控、相反梯度笔画配对、混色文字定位、抗锯齿核心取色、背景冲突拒绝、忽略像素及回退测试。0.2.0 本地包已重建安装，在项目目录外检查命令版本为 0.2.0，依赖检查通过。
- 12 张 1080×2400 示例以 `examples/config.yaml` 运行：`white_card` 只保留背景异常；`dark_text` 的两行配对对比度约 1.17:1；`light_text` 的配对对比度约 1.29:1。`mixed_foreground` 页面单独启用全量模式，仅浅灰的 `weak` 被定位为文字异常，约 1.88:1，正常的 `GOOD` 未被框入。
- 本次批量输出耗时约 7.86 秒，单张算法平均约 1.10 秒、P95 约 3.18 秒；合成集规模和配置较初版不同，不能直接视作算法性能提升或下降的对照实验。结果位于 `reports/20261019T110113Z-613495cb/`。
- 默认专项模式不覆盖白底灰字及中间背景亮度范围的全部可读性问题；全量模式可通过 `examples/all-low-contrast.yaml` 开启。实际产品门限仍需真实截图校准。

## 0.3.0 图片定位验证

- 84 项 pytest 用例通过；新增 21 项图片定位及其工程行为回归。0.3.0 wheel 已构建安装，在项目目录外导入版本为 0.3.0；OpenCV contrib 4.14.0 提供 ximgproc，`pip check` 通过。
- 15 张原尺寸 1080×2400 示例报告：[合成验收报告](../reports/20261019T172328Z-2599abcf/index.html)。共 3 张 `passed`、9 张 `failed`、3 张 `uncertain`，无执行错误。白色天空封面不报背景异常；三张封面旁的白卡仍报背景异常；封面旁弱文字仍报低对比度。包含产物写出的总耗时约 9.92 秒，双并发的单张算法平均约 1.22 秒、P95 约 1.86 秒；不与不同输入的旧版记录直接作性能对照。
- 用户附件扩展名为 PNG、实际编码为 TIFF；保留附件，按原尺寸 1080×2376 无损解码转存为 PNG 后检查。报告原图和定位图尺寸一致，未进行缩放。业务示例报告：[封面页报告](../reports/20261019T172337Z-ad1df3c1/index.html)。
- 此图定位 9 个可信图片区域、1 个不确定候选；同配置仅切换 `pictures.enabled`，背景告警从 6 个降至 1 个，无额外窄边告警，剩余告警位于橙色悬浮 UI 附近。逐条文字结果（含子项）保持一致：10 个低对比度复核项及 6 个无法稳定测量的文字候选，不能据此确认是真实文字缺陷。整页仍为 `uncertain`，模块无错误。
- 图片置信度属于工程评分。深色封面可能范围收缩或只进入复核；浮层与封面重叠时仍可能被框入。合成回归和单张真实示例不提供生产准确率／召回率保证。

## 0.4.0 文字候选验证

- 99 项 pytest 用例通过。新增 15 项可读文字字缝、导航圆角、图片纹理、图片内部弱标签／单个数字、2～3 灰阶弱文字、无可靠测量时不生成对比度及配置校验；旧的整行回退测试改为验证未知分流，未简单删除失败用例。
- `textshape.py` 采用同色比例与连通性、相反极性包围、距离变换局部极大值宽度筛选。`strokes.py` 最多尝试原方向及 ±12°；不放宽取色门限，不合并重复射线。图片内部仍使用完整像素，增加配对和空间支持要求，稳定标签及单字／数字测试保留。
- 删除整行估色告警；仅较强、处于当前检测范围的 UI 文字结构可生成无对比度未知项，其他未测碎片记录诊断。弱候选未输出不代表它已测得正常，测量失败的孤立真实文字仍可能漏检。
- [最新报告](../reports/20261019T173636Z-a0c14f02/index.html)含 15 张合成图和 1 张用户封面页：3 张 `passed`、9 张 `failed`、4 张 `uncertain`，无模块错误。封面页仅剩橙色悬浮 UI 附近的背景复核项，文字低对比度项从 10 降至 0，碎片未知项从 6 降至 0。562 个初始组件中，116 个按同色／字缝／容器规则排除、1 个按宽度规则排除，其他经过配对、范围和支持检查；未测计数保存在 `candidateValidation`，没有隐藏执行错误。
- 该批运行含工件写出约 11.63 秒，单张算法平均 1.32 秒、P95 2.40 秒；并发与样本数和历史运行不同，不能据此宣称性能提升。0.4.0 wheel 已安装，在项目目录外检查版本与依赖通过。
